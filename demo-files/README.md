# Demo files

Sample files for trying the upload features in Ajaia Docs.

| File | Use it for | Expected result |
|---|---|---|
| `1-sprint-retro.md` | **Import file** (dashboard) | New doc with headings, bold/italic, bullet + numbered lists, quote |
| `2-meeting-notes.txt` | **Import file** | New doc, one paragraph per block of text |
| `3-onboarding-guide.docx` | **Import file** | New doc keeping Word headings, bold/italic, both list types |
| `4-pricing-proposal.pdf` | **Import file** → *rejected* (PDF import isn't supported) · **Attach file** → accepted | Clear error on import; downloads fine as an attachment |
| `5-pilot-feedback.csv` | **Attach file** (in a document) | Listed under Attachments, downloadable |
| `6-adoption-chart.png` | **Attach file** | Listed under Attachments, downloadable |
| `7-too-large-for-limit.md` | **Import file** → *rejected* | "… is 2.5 MB. The limit is 2 MB." |
| `8-not-allowed-script.sh` | **Attach file** → *rejected* | "isn't an allowed type" error |
